## Kullanım Örnekleri

### Örnek 1: Metin Formatlama Akışı
```
1. Metin Yaz:
   ┌────────────────────────────────┐
   │ Mahkeme karar vermiştir.       │
   └────────────────────────────────┘

2. Metni Seç:
   ┌────────────────────────────────┐
   │ [Mahkeme] karar vermiştir.     │
   └────────────────────────────────┘

3. Kalın Butonuna Tıkla:
   ┌────────────────────────────────┐
   │ **Mahkeme** karar vermiştir.   │
   └────────────────────────────────┘
```

### Örnek 2: Çeviri Akışı
```
1. Türkçe Metin:
   ┌────────────────────────────────────────┐
   │ Sanığın beraatine karar verilmiştir.   │
   └────────────────────────────────────────┘

2. "Çeviri" → "İngilizce'ye Çevir"
   
3. Sonuç:
   ┌────────────────────────────────────────┐
   │ The defendant has been acquitted.      │
   └────────────────────────────────────────┘
```

### Örnek 3: Sesle Metin Ekleme
```
1. 🎤 Dikte Butonuna Tıkla

2. Mikrofona Konuş:
   "Mahkeme virgül sanığın beraatine karar vermiştir nokta"

3. Sonuç:
   ┌────────────────────────────────────────┐
   │ Mahkeme, sanığın beraatine karar       │
   │ vermiştir.                             │
   └────────────────────────────────────────┘
```
