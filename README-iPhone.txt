Gerekçeli Karar Yazma Programı - iPhone/Safari Paketi

Kullanım:
1. Bu klasörü GitHub reposuna veya herhangi bir statik hosting alanına yükleyin.
2. iPhone'da index.html adresini Safari ile açın.
3. Safari paylaş menüsünden "Ana Ekrana Ekle" seçeneğini kullanın.

Çalışan modüller:
- Gerekçeli karar taslağı
- Ceza hesaplama
- İnfaz hesaplama
- Faiz hesaplama
- Dilekçe yazma ve .txt indirme
- Tazminat ve mahkeme masrafı yaklaşık hesapları
- HTML / Word uyumlu belge indirme

Not:
Bu iPhone paketi Windows .exe dosyasını çalıştırmaz; Electron içindeki web arayüzünü Safari uyumlu hale getirir.
PDF/DOCX içerik ayrıştırma gibi Python backend isteyen masaüstü özellikleri iPhone tarayıcısında sınırlıdır.
